# NormAnzu

NormAnzu is a distributed, event-driven framework that integrates microservices orchestration and intelligent data processing.

NormAnzu is aimed at developers who need a straightforward, dependable solution.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/NormAnzu.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
